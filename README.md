Leonida Legend — an offline guide and tracker for all 55 GTA VI PlayStation 5 trophies, with a roadmap to the platinum, missable flags, and a cited guide for every trophy.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

The guide is plain static files under `app/` — no build step, no network. Open `app/index.html` in a desktop browser with the network off and it works: a checklist saved in the browser (export/import included), filters by grade and kind, a spoiler-safe mode that hides story trophies until earned, a 7-stage roadmap to the platinum built from the official trophy descriptions, and a missable-trophy view flagging the 17 trophies tied to a single story mission, chapter, or strand finale. Every trophy's guide is written in this guide's own words and names its sources (the official PlayStation list via Exophase and the PSNProfiles trophy guide).
